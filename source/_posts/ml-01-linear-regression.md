## 一、初识：它到底是什么

### 1.1 先从"猜体重"说起

朋友报出身高 176cm，让你猜体重，你会怎么想？

多半是这样：回忆见过的人——160cm 差不多 56kg，166cm 大概 60kg，172cm 大概 65kg……身高越高，体重越大。脑子里隐约有一条"线"。

线性回归干的事，和这个直觉一模一样：**把历史数据丢给模型，让它自己找一条最贴合这些点的直线**。以后来了新身高，往直线上一套，体重就出来了。

说白了，机器学习里的"学习"，很多时候就是"从数据里找规律"，而线性回归是最朴实的一种找法。

### 1.2 它在知识地图上的位置

| 维度 | 位置 |
|---|---|
| 学习方式 | 有监督学习（有特征、有标签） |
| 标签类型 | 连续值 → **回归**问题 |
| 和分类的区别 | 回归预测「多少」，分类预测「是哪一类」 |
| 难度 | 第一个模型，最基础的回归算法 |

### 1.3 模型长什么样

一元线性回归就一个式子：

$$y = wx + b$$

两个参数记一下：

- $w$：**权重**（weight），就是直线的斜率。身高每多 1cm，体重平均变多少，看它
- $b$：**偏置**（bias），直线的截距。数学上必须有，现实里不一定有含义

特征多了就叫**多元线性回归**，本质没变：每个特征乘一个权重、加一个偏置。

<details>
<summary>💤 了解即可：矩阵写法（大模型岗位基本不问）</summary>

$$y = w^T x$$

其中 $w = [b, w_1, ..., w_n]^T$，$x = [1, x_1, ..., x_n]^T$。把偏置"藏"进向量里，写代码、推导时更简洁。
</details>

## 二、运用：跑起来，然后把核心搞清楚

### 2.1 先跑起来：五行代码

📌 **工具使用**：会用就行。大模型开发不直接调 sklearn 线性回归，但面试可能问传统 ML 基础。

```python
from sklearn.linear_model import LinearRegression

# 特征必须是二维的：5 个样本、1 个特征
x = [[160], [166], [172], [174], [180]]
y = [56.3, 60.6, 65.1, 68.5, 75]

model = LinearRegression()   # 1. 找个模型
model.fit(x, y)              # 2. 训练：让它自己找最优的 w 和 b
print(model.predict([[176]]))   # 3. 预测 176cm 的体重 → 约 [69.9]

print(f"斜率: {model.coef_}")     # 约 0.93
print(f"截距: {model.intercept_}") # 约 -92.1
```

两个小坑：

- `x` 要写成 `[[160]]` 这种**二维**（sklearn 约定：样本数 × 特征数）。写成 `[160]` 直接报错
- `predict` 也要传二维

---

### 2.2 🔥 损失函数：怎么衡量"这条线画得好不好"

这才是重点。

模型找线的依据是什么？——**误差越小越好**。把所有样本的"预测值减真实值"汇总起来，就是**损失函数（Loss Function）**。线性回归最经典的是**最小二乘法**（误差平方和）：

$$L = \sum_{i=1}^{n}(y_i - \hat{y}_i)^2$$

**为什么是平方？** 三个原因，都很关键：

1. **正负误差不会互相抵消**。直接加起来的话，+5 和 −5 正好抵消，模型"看起来很准"，其实是错的
2. **大误差会被放大**。平方之后，偏离越远的点惩罚越重——模型会更"怕"那些预测得离谱的样本
3. **数学上好处理**：求导方便，而且它等价于"假设噪声服从高斯分布时的最大似然估计"

> 🔥 **往大模型上靠**：MSE（均方误差）是深度学习里最基础的损失函数之一。分类任务用交叉熵，回归任务用 MSE，这是基本功。面试问"为什么用 MSE"，把上面三条答出来就稳了。

### 2.3 🔥 梯度下降：模型到底怎么"找到"最优参数

这是整篇最值钱的部分，**深度学习的所有训练都在重复这一件事**。

把损失函数想象成一座山谷，你站在山坡上某个位置，想走到谷底：

1. 感受脚下哪个方向最陡（算梯度）
2. 往下坡方向走一小步
3. 重复，直到走到谷底

公式：

$$w_{new} = w_{old} - \alpha \cdot \frac{\partial L}{\partial w}$$

- $\alpha$：**学习率**，也就是"每步走多远"，常见 0.001 ~ 0.01
- 梯度指向函数**上升**最快的方向，前面加负号，就是往下降最快的方向走

**学习率是重点里的重点**，记这张表：

| 学习率 | 现象 | 说白了 |
|---|---|---|
| 太大 | 震荡、发散，loss 越跑越大 | 步子迈太大，一脚跨过谷底，越走越偏 |
| 太小 | 收敛极慢，训练半天 loss 不怎么降 | 每次挪一点点，走到天黑还没到谷底 |
| 合适 | 稳定下降，几十到几百轮收敛 | 每一步都稳稳接近谷底 |

> 🔥 **往大模型上靠**：你现在用的 SGD、Adam、AdamW，全都是梯度下降的变体。区别只在"怎么算梯度、每步走多大"。所以这张表不是考线性回归的——是考你懂不懂训练。

<details>
<summary>💤 了解即可：正规方程（对 AI 岗位基本不考，知道名字就行）</summary>

不迭代，直接解方程：

$$\hat{w} = (X^T X)^{-1} X^T y$$

缺点是矩阵不一定可逆（特征高度相关时），而且求逆太慢，所以实际工程里都用梯度下降。
</details>

### 2.4 🔥 过拟合与正则化：模型"学过头"了怎么办

| 状态 | 表现 | 原因 | 怎么治 |
|---|---|---|---|
| **欠拟合** | 训练集、测试集都差 | 特征太少 / 模型太简单 | 加特征、换更强的模型 |
| **正好拟合** | 训练、测试都不错 | —— | 保持 |
| **过拟合** | 训练集很好，测试集拉胯 | 特征太多，把噪声也学会了 | 减特征、正则化、加数据 |

两种正则化，用"管员工"来记最省脑子：

- **L1（Lasso）**：不重要的特征权重直接压到 **0** —— 相当于"不听话就开除"（自动做特征选择）
- **L2（Ridge）**：所有权重都压小，但**不到 0** —— 相当于"不听话就降薪，人还留着"

> 🔥 **往大模型上靠**：深度学习里的 **weight decay 就是 L2 正则化**；Dropout、早停（early stopping）也是防过拟合的手段。微调大模型时"别训太久、学习率别调太大"，本质都是在防过拟合。

### 2.5 📌 评估指标：三个够用

| 指标 | 含义 | 特点 |
|---|---|---|
| MAE | 平均绝对误差 | 单位直观 |
| MSE | 均方误差 | 放大误差，常做损失函数 |
| RMSE | 均方根误差 | 单位还原；若远大于 MAE，说明有个别离谱误差 |

## 三、总结

### 3.1 要点回顾

1. 线性回归 = 找一条最贴合数据的直线，预测**连续值**；核心是 $y = wx + b$
2. 好坏的标准是**损失函数**，最常用最小二乘（MSE）
3. 训练 = **梯度下降**：沿着负梯度方向，一小步一小步挪到谷底
4. **学习率**决定步子大小：太大震荡、太小太慢——这条规律适用于所有深度学习训练
5. 过拟合用**正则化**治：L1 归零（选特征）、L2 缩小（更稳，就是 weight decay）

### 3.2 自测清单

<details>
<summary>Q1：为什么 sklearn 的 x 要写成二维？</summary>

sklearn 约定输入是「样本数 × 特征数」。`[[160], [166]]` = 2 个样本、各 1 个特征。
</details>

<details>
<summary>Q2：学习率过大、过小分别会怎样？</summary>

过大：震荡、发散（loss 不降反升）；过小：收敛极慢。
</details>

<details>
<summary>Q3：L1 和 L2 最本质的区别？</summary>

L1 会把部分权重压到 0（做特征选择），L2 只让权重趋近 0 但不为 0。
</details>

<details>
<summary>Q4：为什么线性回归的损失函数用平方而不是绝对值？</summary>

① 避免正负误差抵消；② 放大异常误差的影响；③ 数学上对应高斯噪声假设下的最大似然估计，求导也方便。
</details>

### 3.3 面试视角（🔥 高频）

| 面试问法 | 答题要点 |
|---|---|
| 线性回归的损失函数是什么？为什么用 MSE？ | 最小二乘；避免抵消、放大误差、高斯噪声下的最大似然 |
| 梯度下降的学习率怎么选？ | 太大震荡、太小太慢；实践中从 1e-3 试起，配合学习率衰减 |
| L1 和 L2 的区别？ | L1 稀疏（可做特征选择），L2 平滑（权重衰减） |
| 过拟合怎么处理？ | 加数据、减特征、正则化、Dropout、早停 |
| 梯度消失/爆炸和这个有关吗？ | 有关：本质是梯度在深层网络里连乘导致过大或过小，学习率过大也会加剧 |
