## 一、初识：AI、机器学习、深度学习，到底是什么关系

这三个词天天一起出现，很多人搞不清。其实用一句话就能说清：

- **AI（人工智能）**：一个**目标** —— 让机器表现出类似人的智能
- **机器学习（ML）**：一种**方法** —— 不写死规则，让机器从数据里自己总结规律（**仿智**）
- **深度学习（DL）**：一种**更具体的方法** —— 用多层神经网络来找规律（**仿生**，模仿大脑神经元）

关系是包含的：**AI ⊃ 机器学习 ⊃ 深度学习**。

| 概念 | 一句话解释 | 打个比方 |
|---|---|---|
| AI | 让机器变聪明 | 想去的地方（目标） |
| 机器学习 | 从数据里找规律，用规律做预测 | 去那里的路（方法） |
| 深度学习 | 用多层神经网络找规律 | 路上跑得最快的那种车 |

> 📌 **面试会怎么问**：几乎必问"AI、机器学习、深度学习的关系"。答"包含关系 + 仿智 vs 仿生"就够漂亮了，别背定义。

## 二、初识：四大学习范式（按"有没有标签"分）

机器学习最核心的分类方式，就看一件事：**数据里有没有"标准答案"（标签）**。

| 范式 | 数据长什么样 | 解决什么问题 | 生活例子 |
|---|---|---|---|
| **监督学习** | 有特征 + **有标签** | 预测 | 给历史房价数据，预测新房价格 |
| **无监督学习** | 只有特征，**没标签** | 聚类 / 找结构 | 把用户按行为自动分成几群 |
| **半监督学习** | 少量标签 + 大量无标签 | 省标注成本 | 医学影像（标注一张片子很贵） |
| **强化学习** | 环境、状态、动作、奖励 | 做决策 | 下棋、机器人走路、玩游戏 |

监督学习内部再分两类，**看标签连续不连续**：

| 类型 | 标签 | 例子 |
|---|---|---|
| **回归** | 连续值（多少） | 预测房价、预测体重 |
| **分类** | 离散值（哪一类） | 判断猫/狗、判断是否欺诈 |

> 📌 **一句话记住**：有标签叫监督，没标签叫无监督；标签连续是回归，标签离散是分类。

## 三、初识：数据里的四个基本术语

后面每篇文章都会用到这套词，先统一语言：

| 术语 | 含义 |
|---|---|
| **样本（sample）** | 一条数据（表格里的一行） |
| **特征（feature）** | 用来做判断的属性（表格里的一列） |
| **标签（label）** | 要预测的那一列 |
| **数据集** | 所有样本的集合，通常拆成**训练集 + 测试集** |

拿"身高猜体重"举个例：

| 身高（特征） | 体重（标签） |
|---|---|
| 160 | 56.3 |
| 166 | 60.6 |
| 172 | 65.1 |

- 三行 = 三个**样本**
- 身高那一列 = **特征**（模型拿它来预测）
- 体重那一列 = **标签**（模型要学的目标）

**为什么要拆训练集和测试集？** 就像学生考试：平时练习题（训练集）做得好不算本事，期末考（测试集）没见过的新题考得好，才是真学会了。常见比例 7:3 或 8:2。

## 四、运用：建模六步流程（所有算法的通用骨架）

这是整个模块最重要的东西——**不管用什么算法，流程都是这六步**：

| 步骤 | 做什么 | 常用工具 |
|---|---|---|
| 1. 准备数据 | 加载数据，看清结构 | `pandas.read_csv` |
| 2. 数据预处理 | 处理缺失值、异常值 | `fillna`、`dropna` |
| 3. 特征工程 | 特征提取 / 缩放 / 编码 / 降维 / 选择 | `StandardScaler`、`get_dummies` |
| 4. 模型训练 | 喂数据，让模型学参数 | `model.fit()` |
| 5. 模型预测 | 用训练好的模型预测新数据 | `model.predict()` |
| 6. 模型评估 | 用指标衡量好坏 | 准确率、MAE、RMSE… |

写成代码模板，后面每篇都会套这个骨架：

```python
from sklearn.linear_model import LinearRegression

# 1. 准备数据
x = [[160], [166], [172], [174], [180]]   # 特征（二维！）
y = [56.3, 60.6, 65.1, 68.5, 75]          # 标签

# 2. 预处理 / 3. 特征工程（本例不需要）

# 4. 训练
model = LinearRegression()
model.fit(x, y)

# 5. 预测
y_pred = model.predict([[176]])

# 6. 评估（回归案例见 ml-01）
print(model.coef_, model.intercept_)
```

> 💡 **记这个骨架就够了**：后面学 KNN、决策树、KMeans，变的只是第 4 步"用哪个模型"，其他五步几乎一模一样。

## 六、一个贯穿全模块的问题：过拟合

模型"学得好不好"，永远逃不开三种状态：**欠拟合 / 正好 / 过拟合**。

这个概念我在《[线性回归](https://liansir0506.github.io/Liansir0506.github.study/2026/10/20/ml-01-linear-regression/)》那一篇里已经讲透了（它同时也是正则化的前置知识），这里只留一个记忆锚点：

> **过拟合 = 练习题刷得太熟，考试反而砸了**（死记硬背，不会变通）。

后面每一篇遇到"模型太复杂"「正则化」「剪枝」这些词，都是在跟过拟合作斗争。

## 三、总结

### 3.1 要点回顾

1. **AI 是目标，机器学习是方法（仿智），深度学习是方法中的一种（仿生）**，三者层层包含
2. 四大范式按"有没有标签"分：监督、无监督、半监督、强化；监督学习再看标签连续与否，分为回归和分类
3. 样本 / 特征 / 标签 / 训练集 / 测试集 —— 这套词是后面所有文章的共同语言
4. **建模六步流程**（准备 → 预处理 → 特征工程 → 训练 → 预测 → 评估）是通用骨架，换算法只换第 4 步
5. 过拟合是贯穿整个机器学习的主线问题，治法：正则化、减特征、加数据

### 3.2 自测清单

<details>
<summary>Q1：监督学习和无监督学习最本质的区别？</summary>

数据里有没有标签。有标签 → 监督（学"输入到输出"的映射）；没标签 → 无监督（自己找数据结构，如聚类）。
</details>

<details>
<summary>Q2：回归问题和分类问题怎么区分？</summary>

看标签：连续值（房价、体重）是回归；离散类别（猫/狗、是否违约）是分类。
</details>

<details>
<summary>Q3：为什么一定要留出测试集？</summary>

评估模型的"泛化能力"。用训练集打分是自欺欺人——模型可能只是把训练数据背下来了（过拟合），测试集才模拟"面对没见过的新数据"。
</details>

<details>
<summary>Q4：建模六步流程背一遍？</summary>

准备数据 → 数据预处理 → 特征工程 → 模型训练 → 模型预测 → 模型评估。
</details>
