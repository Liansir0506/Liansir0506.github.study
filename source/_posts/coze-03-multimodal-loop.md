## 一、初识：大模型的"感官"

纯文本模型只能"读字"，多模态模型还能"看图、听音"：

| 模态 | 能力 | 典型场景 |
|---|---|---|
| **图片** | 识图、OCR、图表理解 | 截图问答、发票识别、看图写文案 |
| **语音（ASR）** | 语音转文字 | 会议记录、面试录音分析 |
| **语音（TTS）** | 文字转语音 | 有声内容、语音助手 |
| **文件** | 解析 PDF/Word/表格 | 合同审阅、简历筛选 |

> 🔥 记住两个缩写：**ASR（语音识别，语音→文字）** 和 **TTS（语音合成，文字→语音）**。面试聊语音交互场景时经常出现。

## 二、初识：多模态在 Coze 里怎么用

### 2.1 图片输入

- Bot 对话框支持直接上传图片
- 模型（需支持视觉）能"看到"图片内容
- 常见用法：用户传截图问"这个报错怎么解决"、传简历图片做信息抽取

### 2.2 语音输入输出

- 平台上可以给 Bot 配置语音能力：用户说话 → ASR 转文字 → 模型处理 → TTS 朗读回复
- 典型场景：**模拟面试、口语练习、语音助手**

### 2.3 文件处理

- 上传 PDF/Word → 平台解析文字 → 模型处理
- 配合知识库：文档进知识库，问答时检索

## 三、初识：循环结构——批处理的关键

### 3.1 循环节点是什么

普通工作流是"一条路走到底"；**循环节点**能对**一个列表**逐项处理：

```text
输入：一个简历列表 [简历A, 简历B, 简历C]
  ↓ 循环节点（对每一项）
    → 提取信息
    → 评估打分
    → 输出结果
  ↓
输出：三个结果拼成的列表
```

### 3.2 循环的三个配置项

| 配置 | 说明 |
|---|---|
| **循环输入** | 要遍历的数组（列表） |
| **循环体** | 每一项要执行的操作（可以是一串节点） |
| **循环输出** | 每项结果汇总（数组） |

### 3.3 什么时候用循环

| 场景 | 例子 |
|---|---|
| 批量文档处理 | 100 份简历批量提取关键信息 |
| 批量生成 | 一个主题生成 10 条不同角度的文案 |
| 逐项校验 | 每条回复都检查是否含违禁词 |

> ⚠️ 注意成本：循环 N 次 = N 次模型调用。批量大时先估算费用和时间。

## 四、运用：多模态 + 循环的组合

最典型的组合场景（也是 AI 面试助手用到的）：

```text
用户上传：一段 40 分钟的面试录音 + 简历
  ↓ ① ASR 语音转文字（多模态）
  ↓ ② 文字按对话轮次切片（代码节点）
  ↓ ③ 循环节点：逐轮分析
       - 问题是什么？
       - 回答是否准确？（对照知识库里的面试宝典）
       - 回答有哪些问题？
  ↓ ④ 汇总生成报告（大模型节点）
  ↓ ⑤ 输出：面试表现评估报告
```

**为什么要循环？**——因为录音太长，一次性让模型分析整段录音会：
- 超出上下文长度
- 注意力分散，细节丢失
- 不如"逐轮分析再汇总"准确

> 💡 这是处理长文档/长对话的通用套路：**先切片，再逐块处理，最后汇总**。后面 RAG 项目的文档入库也是同一思路。

## 五、总结

### 5.1 要点回顾

1. 多模态 = 图片 / 语音（**ASR 转文字、TTS 转语音**）/ 文件
2. 循环节点 = 对列表逐项处理，配置为"循环输入 + 循环体 + 循环输出"
3. 循环的代价：N 次模型调用 = N 倍成本与时间
4. **长内容处理套路**：切片 → 循环逐块处理 → 汇总
5. 多模态 + 循环的典型组合：录音转写 → 逐轮分析 → 汇总报告

### 5.2 自测清单

<details>
<summary>Q1：ASR 和 TTS 分别是什么？</summary>

ASR（Automatic Speech Recognition）：语音转文字；TTS（Text To Speech）：文字转语音。
</details>

<details>
<summary>Q2：循环节点适合什么场景？</summary>

对数组逐项做同样的处理：批量文档抽取、批量生成、逐条校验。
</details>

<details>
<summary>Q3：为什么长录音要"切片 + 循环"而不是一次分析？</summary>

上下文长度有限、一次性输入会让模型注意力分散漏细节；切片逐块分析再汇总更准确、更可控。
</details>

### 5.3 面试视角（📌）

| 面试问法 | 答题要点 |
|---|---|
| 多模态大模型能做什么？ | 图文理解、语音识别/合成、文档解析；多模态 RAG（图片检索） |
| 长文档/长录音怎么处理？ | 切片 + 循环逐块处理 + 汇总；或摘要压缩后再分析 |
| 批量任务怎么控成本？ | 限流并发、小模型跑粗筛、缓存重复结果、异步队列 |
| 语音交互链路？ | 麦克风 → ASR → LLM → TTS → 播放 |
