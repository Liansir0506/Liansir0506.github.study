## 一、初识：为什么需要深度学习

### 1.1 机器学习的天花板

回顾一下机器学习：线性回归、决策树、随机森林……它们都有一个共同前提——**特征是人挑的**。

比如判断一张图是不是猫，传统做法是：人先定义好"有尖耳朵""有胡须""毛色"这些特征，再交给模型去学。

但这里有两个绕不过去的坎：

1. **有些问题，人工特征根本设计不出来**——你怎么用数字描述一只猫的"猫感"？
2. **有些问题，人工特征设计起来太复杂、太贵**——依赖专家、费时费力

### 1.2 深度学习的思路：连特征一起学

深度学习（Deep Learning）的想法很直接：**既然人设计特征这么难，那就让网络自己学。**

- 网络有很多层：输入层 → 隐藏层（好几层）→ 输出层
- 每一层都从上一层的结果里**自动提取更抽象的特征**
- 处理图像时，浅层学到"边缘"，中层学到"纹理和部件"，深层学到"整只猫"

> 一句话对比：
> **机器学习 = 人找特征 + 机器找规律**
> **深度学习 = 机器连特征带规律一起找**

这就是为什么深度学习在图像、语音、自然语言这些"人很难描述特征"的领域大放异彩。

## 二、初识：三大网络结构的分工

深度学习不是一个算法，而是一类模型。按"处理什么数据"分，主要有三种：

| 网络 | 全称 | 擅长处理 | 典型应用 |
|---|---|---|---|
| **ANN** | 人工神经网络（全连接） | 表格 / 通用数值数据 | 分类、回归、价格预测 |
| **CNN** | 卷积神经网络 | **图像** | 图像分类、目标检测 |
| **RNN** | 循环神经网络 | **序列 / 文本** | 文本生成、机器翻译 |

这三兄弟的共同点是"神经元 + 层"，区别在于层里的**连接方式**不同。后面 dl-06、dl-07 会分别展开 CNN 和 RNN。

## 三、初识：核心循环——正向传播与反向传播

这是整个深度学习的"心脏"，值得花五分钟看明白。

### 3.1 正向传播：从输入算出预测和损失

$$\underbrace{X}_{\text{输入特征}} \xrightarrow{\times W + B} \underbrace{Z}_{\text{预测值}} \xrightarrow{\text{和真实值 } Y \text{ 比}} \underbrace{Loss}_{\text{损失}}$$

- 输入 X 乘上权重 W、加上偏置 B → 得到预测值 Z
- 预测值和真实值 Y 一比 → 得到损失 Loss（差距有多大）

### 3.2 反向传播：从损失倒推怎么改

$$Loss \xrightarrow{\text{求导}} \text{梯度} \xrightarrow{\text{更新}} W_{新} = W_{旧} - \text{学习率} \times \text{梯度}$$

- 对损失函数求导，得到"往哪个方向改、改多少"的梯度
- 按梯度反方向迈一小步，更新每一个 W 和 B
- 重复"正向 → 反向"，损失越来越小，模型越来越好

> 用做题打个比方：**正向传播是"做题"，反向传播是"对答案、改错题"。** 做完一套题、对完答案、发现自己哪类题老错，下次就重点练——这就是训练。

### 3.3 神经元与全连接层

深度学习的最小单位是**神经元**：

> **神经元 = 加权求和 + 激活函数**

- 加权求和：把输入乘权重、加起来（线性变换）
- 激活函数：套一个非线性函数，让网络能学会"弯曲"的关系

而**全连接层**的意思是：这一层的每一个神经元，都和上一层的**所有**神经元相连，但同一层的神经元之间互不相连。

## 四、初识：深度学习的四个特点

| 特点 | 说明 |
|---|---|
| **层级堆叠** | 输入层 → 隐藏层 → 输出层，一层套一层 |
| **特征自动化** | 不需要人工设计特征，网络自己学（最大优势） |
| **吃数据、吃算力** | 需要大数据 + GPU 加速，小数据上反而不如传统方法 |
| **黑盒** | 可解释性差；至于为什么用 3 层、18 层、100 层，业界也没有公认的理论解释 |

## 六、总结

### 6.1 要点回顾

1. 深度学习 = **多层神经网络**，最大优势是**自动学特征**（对比机器学习的人工特征工程）
2. 三大结构：**ANN**（表格）、**CNN**（图像）、**RNN**（序列），区别在"层与层的连接方式"
3. 训练的核心循环：**正向传播算损失 → 反向传播算梯度 → 梯度下降更新参数**
4. 神经元 = **加权求和 + 激活函数**；全连接层 = 每个神经元连接上一层全部神经元
5. 深度学习的代价：需要大数据和算力，而且**不可解释**

### 6.2 自测清单

<details>
<summary>Q1：深度学习和传统机器学习最本质的区别？</summary>

特征由谁来找。机器学习依赖人工设计特征，深度学习把特征提取也交给网络自动完成（多层次抽象）。
</details>

<details>
<summary>Q2：正向传播和反向传播各干什么？</summary>

正向传播：输入经过层层计算得到预测值，再与真实值比较得到损失；反向传播：对损失求导得到梯度，反向逐层更新参数（W = W − lr × 梯度）。
</details>

<details>
<summary>Q3：为什么必须要有激活函数？</summary>

如果没有激活函数，多层线性变换叠加起来仍然是一个线性变换（等价于一层），网络再深也无法拟合非线性关系。激活函数的作用是引入非线性。
</details>

<details>
<summary>Q4：CNN 和 RNN 分别适合什么数据？</summary>

CNN 适合图像（局部特征 + 参数共享）；RNN 适合序列数据（文本、语音，需要"记忆"上下文）。
</details>

### 6.3 面试视角（📌）

| 面试问法 | 答题要点 |
|---|---|
| 深度学习和机器学习的区别？ | 自动特征 vs 人工特征；数据/算力需求更高；可解释性更差 |
| 神经网络是怎么训练的？ | 正向传播算 loss → 反向传播（链式法则）算梯度 → 优化器更新参数，循环迭代 |
| 为什么需要激活函数？ | 引入非线性；否则多层网络退化为单层线性变换 |
| 深度学习的缺点？ | 黑盒不可解释、依赖大数据和算力、容易过拟合、调参成本高 |
| 为什么深度学习需要 GPU？ | 大量矩阵乘法可并行计算，GPU 并行能力强 |
