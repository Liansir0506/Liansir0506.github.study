> **一句话概括**：把一群"弱模型"组合成一个"强模型"——Bagging 靠并行投票降方差，Boosting 靠串行纠错降偏差。
> **这篇有多重要**：📌 —— "bagging vs boosting" 是面试常考概念；GBDT / XGBoost 系列是传统 ML 岗的核心武器，大模型岗位了解思路即可。

## 一、初识：为什么要"抱团"

### 1.1 单个模型的毛病

回想 ml-04 的结论：**一棵决策树特别容易过拟合**——训练集背得滚瓜烂熟，测试集一考就露馅。

这背后是模型的两个老毛病：

| 毛病 | 通俗理解 | 集成怎么治 |
|---|---|---|
| **偏差大**（欠拟合） | 模型太笨，怎么学都学不会 | Boosting：一群模型接力纠错 |
| **方差大**（过拟合） | 模型太敏感，数据一变就翻车 | Bagging：一群模型投票，个别翻车不影响大局 |

**集成学习（Ensemble Learning）** 的核心思想：**一个人不靠谱，那就组个团。**

而且有个反直觉的数学结论：只要每个模型"比瞎猜略好"且彼此**有差异**，组合起来就能变得很强。

### 1.2 两条路线，一句话区分

| 路线 | 训练方式 | 组合方式 | 主打 |
|---|---|---|---|
| **Bagging** | **并行**（各自独立训练） | 平权投票 / 平均 | 降方差（更稳） |
| **Boosting** | **串行**（后一个盯着前一个的错误练） | 加权投票 | 降偏差（更准） |

## 二、Bagging：随机森林

### 2.1 三步走

1. **有放回抽样（bootstrap）**：从原始数据里有放回地抽 N 个样本，训练一棵树——抽 M 次，得到 M 棵树
2. **并行训练**：这 M 棵树互相独立，可以同时训练
3. **平权投票 / 取平均**：分类看票数，回归取平均

### 2.2 随机森林的"随机"体现在哪（面试爱问）

| 随机点 | 怎么随机 | 作用 |
|---|---|---|
| **样本随机** | 每棵树用 bootstrap 抽到不同的数据子集 | 让树看到的数据不一样 |
| **特征随机** | 每次分裂只从**随机一部分特征**里挑最好的 | 让树的"思路"不一样 |

> 为什么要两重随机？——如果每棵树都看一样的数据、用一样的特征，那它们会长得**一模一样**，集成没有意义。**集成的前提是"成员之间有差异"。**

### 2.3 随机森林为什么好

- 一堆树投票 → 个别树的偏差被抵消 → **不容易过拟合**
- 并行训练 → 快（相对 boosting）
- 对参数不那么敏感、对异常值也不像单棵树那么敏感

## 三、Boosting：AdaBoost

### 3.1 思路完全不同

Bagging 是"群策群力"，Boosting 是"**接力补短板**"：

1. 先训练一个弱模型
2. **看看它哪些样本分错了 → 把这些样本的权重调高**
3. 下一个模型重点练这些"硬骨头"
4. 重复 N 轮，最后把所有模型**加权投票**（表现好的模型话语权更大）

### 3.2 一句话对比

> **Bagging：一群人各自做题，最后对答案。**
> **Boosting：一个学生做错的题，下一个学生重点做，最后按成绩加权汇总。**

## 四、Bagging vs Boosting（面试就答这张表）

| 维度 | Bagging（随机森林） | Boosting（AdaBoost / GBDT） |
|---|---|---|
| 训练方式 | **并行**，模型互不依赖 | **串行**，后一个依赖前一个 |
| 数据使用 | 有放回抽样（bootstrap） | 全量数据，调整样本权重 |
| 关注点 | 降低**方差**（更稳定） | 降低**偏差**（更准确） |
| 组合方式 | **平权**投票 / 平均 | **加权**投票 |
| 过拟合风险 | 低（树越多越稳） | 需要控制轮数，否则会过拟合 |
| 代表算法 | 随机森林 | AdaBoost、GBDT、XGBoost、LightGBM |
| 训练速度 | 快（可并行） | 慢（必须串行） |

## 五、运用：随机森林实战

还是泰坦尼克号的数据，这次把"一棵树"换成"一片森林"：

```python
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import GridSearchCV

# 基础用法
rf = RandomForestClassifier(n_estimators=100, max_depth=5, random_state=42)
rf.fit(x_train, y_train)
print(rf.score(x_test, y_test))

# 网格搜索调参：树的数量 + 深度
param_grid = {
    "n_estimators": [50, 100, 200],
    "max_depth": [3, 5, 7],
}
grid = GridSearchCV(RandomForestClassifier(random_state=42), param_grid, cv=4)
grid.fit(x_train, y_train)

print("最优参数:", grid.best_params_)
print("最优分数:", grid.best_score_)
```

> 📌 `n_estimators`（树的数量）不是越多越好：到一定程度收益饱和，但训练时间线性增长。100~300 通常够用。

AdaBoost 也顺手记一下 API：

```python
from sklearn.ensemble import AdaBoostClassifier

ada = AdaBoostClassifier(n_estimators=50)
ada.fit(x_train, y_train)
```

## 六、💤 延伸一句：GBDT 家族

传统 ML 岗位的"大杀器"是 **GBDT（梯度提升树）** 及其工程实现 **XGBoost / LightGBM**——表格数据比赛（Kaggle 表格类）的常胜将军。

关系链条记一下就行：

> AdaBoost（加权纠错）→ GBDT（用梯度代替权重）→ XGBoost / LightGBM（工程优化版）

大模型岗位面试一般不深挖，但能说出这条演进线是加分项。

## 七、总结

### 7.1 要点回顾

1. 集成学习 = 把多个弱模型组合成强模型；前提是**成员之间有差异**
2. **Bagging（随机森林）**：样本有放回抽样 + 特征随机 + 并行 + 平权投票 → 降方差
3. **Boosting（AdaBoost）**：串行训练，专攻上一个模型分错的样本 + 加权投票 → 降偏差
4. 随机森林的"随机"是两重：**样本随机 + 特征随机**
5. GBDT / XGBoost / LightGBM 是 Boosting 路线的进阶版，表格数据的王者

### 7.2 自测清单

<details>
<summary>Q1：随机森林的"随机"体现在哪两个地方？</summary>

① 样本随机：每棵树对有放回抽样得到的子集训练；② 特征随机：每次分裂只考虑随机选取的部分特征。
</details>

<details>
<summary>Q2：Bagging 和 Boosting 最本质的区别？</summary>

Bagging 并行训练、平权投票，主要降方差；Boosting 串行训练、后一个纠正前一个的错误、加权投票，主要降偏差。
</details>

<details>
<summary>Q3：为什么随机森林不容易过拟合？</summary>

多棵"有差异"的树投票，个别树的偏差/噪声被平均掉；且每棵树只看到部分数据和特征，单棵树不会过度拟合全量数据。
</details>

<details>
<summary>Q4：树的数量越多越好吗？</summary>

不是。增加到一定程度后效果趋于饱和，但训练和预测开销持续上升。通常 100~300 够用，配合网格搜索确定。
</details>

### 7.3 面试视角（📌）

| 面试问法 | 答题要点 |
|---|---|
| 什么是集成学习？ | 组合多个弱模型成强模型；成员要有差异性 |
| Bagging 和 Boosting 的区别？ | 并行 vs 串行；平权 vs 加权；降方差 vs 降偏差 |
| 随机森林的随机性？ | 样本随机（bootstrap）+ 特征随机（分裂时随机选特征子集） |
| 为什么集成能提升效果？ | 抵消个体模型的偏差/方差；错误不完全相关时投票能纠偏 |
| XGBoost 和随机森林的区别？ | Boosting（串行、加法模型、拟合残差）vs Bagging（并行、独立树、投票） |
